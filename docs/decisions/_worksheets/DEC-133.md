# DEC-133 — worksheet

**Source:** `docs/decisions/DEC-133-the-customer-availability-screen-is-server-rendered.md`, 2,481 bytes, no amendments, task 12.4 / issue #457. Revised in part by DEC-156.

Evidence is mechanical only — does the file exist, does the column exist, does the route resolve, is there a test. Absence is stated as absence. Evidence never decides a verdict.

**Verdicts — six values.** The question every verdict answers: *does this ruling govern what I'm building now?* Code existing is evidence, not verdict.

| verdict | means | action |
|---|---|---|
| **TRUE** | Governs current work and is accurate. | Rewrite into schema, keep the DEC id. |
| **FALSE** | Governs current work but is wrong — the system doesn't behave this way. | Rewrite into schema, `status: superseded`. **Open an issue.** |
| **DEAD** | Doesn't govern current work. Superseded, or covers a feature cut from §2.8. Code may still exist and even be tested; irrelevant to the verdict. | Drop the ruling from the rewritten record. **No tombstone banner.** Issue only where dead rulings orphan real code — one per group, not per ruling. |
| **UNKNOWN** | Can't be adjudicated. Never tested, or provenance unclear. | Keep the ruling. **Open an issue** to investigate. |
| **MOVE** | Not a ruling at all — a fact about the world, not a choice that could have gone otherwise. Tax rates, jurisdictions, vendor limits. | Remove from the record. SPEC names **where the value lives**, never what it is. |
| **DELETE** | A concrete value swallowed into the record. Rates, thresholds, timings, limits. | Remove. Write the value nowhere. If no document names its source, open an issue for that. |

**MOVE vs DELETE:** MOVE is a fact that needs documenting somewhere; DELETE is a value that must not be copied anywhere. A row can be both — the fact moves, the number dies.

**Whole-record archive** (`docs/decisions/archive/`) applies only when every ruling is DEAD. Filename and ID preserved so citations resolve. Never delete a record file.
