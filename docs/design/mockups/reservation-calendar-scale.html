Decisions — and what's still stewing (2026-07-20)

  • Day view — build ONE, not both. Timeline and Grid are the same data (one rotated). Leaning Grid — whichever reads best once you're used to it. Both are left here only to compare; only one ships.
  • Week — low priority, maybe cut. Might never get used. Kept as a summary concept, not a commitment.
  • Month — right shape, thin blocks. Utilization + clean is correct, but each day-cell needs to carry more information before it's the real thing. Parked.
  • Honesty rule stays everywhere: opens are all-or-none via filter; a blank never secretly means "open."
  • Status: Week + Month are parked to stew — real improvements, not being updated now. The one near-decision is Day = Grid.
