back-pointer. `{id, relation, scope}` declared once generates both ends — the index annotation

Ctrl-F, not via the index. 36 edges / 27 amended decisions, two of which Z2's source-side table
missed (DEC-061/063→DEC-007, DEC-079/081→DEC-010), found by cross-checking each body's existing
